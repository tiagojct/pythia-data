Pythia: hand check of the coder

Read the event. A code is correct if a careful reader with the codebook gives the same code. For each wrong code, press its key or its button. A correction is optional. An empty anchor means "no anchor", and it is correct when no anchor event says the same thing.

Keys: 1, 2, 3 mark a code as wrong (press again to undo). Enter or right arrow: next. Left arrow: back. The marks stay in this browser. Download the result at the end and put it in data/coded/.
